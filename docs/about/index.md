# 关于本站

RM 苍穹战队硬件组的培训与知识库，由队员共同维护。

## 这是什么

- 面向**新队员**的七周培训计划与配套资料
- 面向**所有队员**的硬件知识索引
- ==不是==战队或学校的官方文档，内容不代表官方立场

## 内容来源

| 七周培训计划 | 硬件组《秋招第一月按周考核安排》原始文本 |

## 技术栈

站点基于 [VitePress](https://vitepress.dev/) 构建，同时发布到 GitHub Pages 和战队内网服务器，两边共用一份代码。

- 侧边栏由目录结构自动生成，==新建 md 文件即自动出现在导航里==
- 全文搜索用 [Pagefind](https://pagefind.app/)，构建期生成索引，纯静态
- 每页的「最后更新」「贡献者」「页面历史」从 git 历史读出，不用手写
- 周进度、物料这类会变的数据集中放在 `docs/.vitepress/data/`

想改内容或加页面，看[参与编写](/about/contribute)。
