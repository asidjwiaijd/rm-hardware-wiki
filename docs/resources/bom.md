# 物料总清单

六周采购项的汇总。==建议第一周先把前三周的东西一起买了==，能省运费，也不会卡在等快递上。

## 基础器件（第 1 周）

| 物品                 | 规格 / 说明                |
| -------------------- | -------------------------- |
| 面包板               | 免焊接搭电路               |
| 阻容器件包           | 插件件与 0603 贴片件都要   |
| LED 包               | 各色直插                   |
| 三极管               | S8050（NPN）、S8550（PNP） |
| 杜邦线               | 公对公、公对母             |
| 常用 IC 收纳盒       | 后面几周会陆续买芯片       |
| STM32F103C8T6 开发板 | 功能由预算决定             |

## 模拟电路（第 2 周）

| 物品         | 规格 / 说明                      |
| ------------ | -------------------------------- |
| 运放芯片     | LM324（四运放）、LM358（双运放） |
| 蓝白电位器   | 调亮度、做 ADC 输入源都用得上    |
| 打样基础元件 | 按你自己画的板子的 BOM 买        |

## 电源链路（第 3 周）

| 物品             | 规格 / 说明                                 |
| ---------------- | ------------------------------------------- |
| 锂电池           | 3.7V 可插拔，==容量 ≥500mAh==               |
| USB 输入口       | microUSB 两脚座（焊接难度低）或其他 5V 输入 |
| 充电芯片         | 或成品充电模块                              |
| 升压芯片         | 3.7V → 5V（BOOST）                          |
| 降压芯片         | 5V → 3.3V（BUCK）                           |
| LDO              | 3.3V → 2.5V                                 |
| 电感、电容、电阻 | 按所选芯片数据手册配                        |
| 接口座、排针     | 按设计选                                    |

## 焊接与调试（第 4 周）

| 物品              | 规格 / 说明            |
| ----------------- | ---------------------- |
| 焊锡丝            | 含铅的更好焊，注意通风 |
| 助焊剂            | 松香或免洗助焊剂       |
| 吸锡带            | 拆错件、清多余锡       |
| 排针、热缩管      |                        |
| USB 数据线        | 注意别买到只能充电的线 |
| **电烙铁 / 焊台** | 可以先用实验室的       |
| **万用表**        | ==必备，全程都要用==   |
| **ST-Link**       | 下载和调试             |

## 最小系统板（第 5 周）

| 物品               | 规格 / 说明                    |
| ------------------ | ------------------------------ |
| STM32F103C8T6 芯片 | 注意封装（LQFP48）             |
| 8MHz 晶振          | 及配套负载电容，按晶振手册选值 |
| 复位按钮           |                                |
| BOOT 跳帽          | 或用电阻固定电平               |
| 3.3V 稳压器        |                                |
| SWD 接口座、排针座 |                                |
| 指示灯、限流电阻   |                                |

## 通信整合（第 6 周）

| 物品                | 规格 / 说明            |
| ------------------- | ---------------------- |
| 电位器或模拟传感器  | ADC 输入源             |
| USB 转串口模块      | CH340 / CP2102 都行    |
| 待联调的下位机模块  | 按你的演示方案选       |
| 示波器 / 逻辑分析仪 | 有则更好，实验室通常有 |

:::tip 省钱提示

- 电烙铁、万用表、示波器这类工具==先问实验室有没有==，不用自己全买
- 阻容件买"包"比单买划算，但要确认包含常用值
- 芯片在立创商城下单时，嘉立创 EDA 里能直接看库存和价格

:::

:::warning
锂电池属于危险品，部分快递不收或需要特殊渠道。买之前先确认能不能寄到，==不要买到没有保护板的裸电芯==。
:::
