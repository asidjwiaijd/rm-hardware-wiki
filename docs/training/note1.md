# 第 1 周 · 培训讲义

## 硬件导论

### 硬件组的工作内容

在招新阶段已经介绍过，团队划分为**机械**、**电控**、**算法**、**硬件**四个组别。

机械组负责整车的骨架，例如玻纤板、碳板、轴承等与电无关的工作内容。其余涉及代码的工作内容分为两部分：控制整车运行的程序由电控组负责，运行于上位机、运算平台的程序由算法组负责。除此之外，一切与电相关的内容均由硬件组负责。

具体包括：

| 项目         | 说明                                       |
| ------------ | ------------------------------------------ |
| 走线         | 整车线束的设计与布置                       |
| 分电板       | 将电池电能按需分配至各用电模块             |
| 超级电容系统 | 为整车提供瞬时大功率补充                   |
| 无线充电系统 | 无线传输电力                               |
| DC/DC        | 将电池电压变换为各模块所需的电压           |
| 继电器       | 大电流回路的通断控制                       |
| FOC          | 无刷电机的驱动，决定电机能否转动及转动品质 |
| 主控板       | 承载车载程序运行的 MCU 系统板              |
| 交换机       | 车载网络的数据交换节点                     |
| 板间通信     | CAN、UART、SPI、I2C……                      |

:::info 总括
硬件组的工作，就是将电池中的电能，安全、稳定、高效地输送至各个需要它的位置。
:::

### 培训目标

- 掌握常见电学元器件的运用

:::

## PCB 工艺

### 什么是 PCB

PCB 是一种将电子元件固定并连接起来的机械基板，也是电子产品的重要组成部分，几乎存在于所有的现代电子设备中。

例如：电脑主板、手机主板、RM C 型开发板、苍穹分电板等。

为什么需要 PCB：稳定易维护、体积小、能量损耗少。

- **稳定易维护**：PCB 的电气连接由铜箔直接构成并固定在板内，焊点牢固，不会像杜邦线连接那样因触碰而松脱
- **体积小**：相同电路采用 PCB 实现时，体积与重量均远小于手工焊接的版本
- **能量损耗少**：走线宽度可按电流大小设计，接触电阻小，大电流下发热更少

![面包板搭出来的电路](/note1/image-20260917193934748-17896451771791.png)

> 面包板搭建的电路：可以工作，但可靠性、便利性与美观度均较差

:::tip 面包板是否还有必要
调试阶段使用面包板快速验证电路方案，比绘制 PCB 并打样快得多。但**凡是要装车的电路，都必须采用 PCB 实现**：车上的振动、大电流与电磁环境，均超出面包板的承受能力。
:::

PCB 并非单一的"塑料板"，而是由多层结构叠合而成：

| 层次                            | 作用                                                   |
| ------------------------------- | ------------------------------------------------------ |
| 基材（Substrate）               | FR-4 玻纤板，绝缘、提供机械支撑                        |
| 铜箔（Copper）                  | 导电层，即所绘制的"走线"本身                           |
| 阻焊层（Solder Mask）           | 绿色的那层绝缘漆，防止焊接时连锡，同时保护铜箔不被氧化 |
| 丝印层（Silkscreen）            | 白色的字和框，标出元件位号和轮廓，方便焊接和维修       |
| 表面处理（喷锡 / 沉金 / OSP……） | 保护裸露的铜焊盘，直接影响焊接的难易和保存时间         |

:::info 沉金工艺的作用
喷锡（HASL）成本低、易焊接，但表面不平整，细间距芯片容易连锡；沉金（ENIG）表面平整、保存时间长，适用于引脚密集的芯片，但成本更高。初学阶段采用默认的喷锡工艺即可。
:::

### PCB 层压结构

#### PCB 叠层的基本组成

PCB 叠层（PCB Stack-up）通常由导电铜箔（信号层和电源/地层）和绝缘材料（介质层）交替组成。合理的叠层设计对 PCB 的电气特性、物理性能、机械性能、可靠稳定性和制造成本等至关重要。

层数：目前硬件任务中多使用 2 层板与 4 层板。

基板材质：一般为铝/FR-4。铝基板只有单层板，但具有非常良好的导热性能。

![叠层与铜厚](/note1/e027b82f0feadad99fa23223b217fdf1.png)

> 两/四/六层板的叠层示意，注意每层标注的铜厚

:::info 图中标注的含义

- **Prepreg（半固化片）/ Core（芯板）**：压合时用于粘合铜箔与铜箔的材料，图中标注的 0.2mm、1.2mm 即为它们的厚度
- **铜厚以"盎司（oz）"为单位**：1oz 指在 1 平方英尺的面积上铺设 1 盎司铜，换算为厚度约 **35µm**。图中外层 `1OZ/0.035mm`、内层 `0.5OZ/0.017mm` 即为此意。铜层越厚，可承受的电流越大，但可绘制的最小线宽也越大
- **FR-4**：最主流的 PCB 基材，由玻璃纤维布浸渍环氧树脂压制而成，`F` 表示阻燃（Flame retardant）
  :::

- 双层板：包含两层导电铜箔层，中间是绝缘介电层。

![双层板叠层](/note1/laminated-structure_20250116_210613.jpg)

- 四层板：包含四层导电铜箔层，每两层铜箔中间夹一层绝缘介电层。通常在靠近元器件多的内层里铺一层完整的 GND。

![四层板叠层](/note1/laminated-structure_20250116_210629.jpg)

- 六层板及以上：增加了更多的导电铜箔层，每两层铜箔中间夹一层绝缘介电层，提供更好的电源分配和信号隔离。

:::warning 四层板并非简单地增加层数
四层板真正的价值在于：**中间层可以设置一整层完整的 GND**。信号层紧邻地平面，回流路径最短、阻抗最可控，电源与信号之间的相互干扰也显著减小。若叠层顺序编排不当（例如两个信号层相邻、地平面被分割得支离破碎），四层板的效果并不比两层板有明显优势。
:::

#### 叠层设置的基本原则

- 主芯片相邻层为地平面，在布线时提供良好的参考地平面（回流路径最短）
- 信号层尽量避免直接相邻，以减少串扰
- 所有信号层最好与地平面相邻，以保证完整信号的回流
- 主电源尽可能与地平面相邻，降低电源平面阻抗

参考：[嘉立创 EDA 教育与开源文档中心](https://wiki.lceda.cn/zh-hans/)

:::tip 板材层数的选择
两层板适用的场合：电路结构简单、无高速信号、电流不大的板子。四层板适用的场合：含有 MCU、开关电源或高速通信（如以太网、USB）的板子。难以判断时，建议先用两层板完成原理图验证，再考虑是否升级为四层板。
:::

### PCB 结构

#### 走线

PCB 每层都有各种不同的网络，靠不同大小、形状的铺铜与走线，把元件相互连接

![PCB 布线实况](/note1/image-20260917195901964.png)

- **走线宽度**由电流大小决定。电流越大，线要越宽；信号线可以很细
- **铺铜**：将整层大面积铺满铜皮并连接至某个网络（一般为 GND），可以降低阻抗、帮助散热、屏蔽干扰
- **安全间距**：导线与导线之间的距离。电压越高，间距应越大，否则存在击穿和爬电的风险

:::tip 线宽估算
1oz 铜厚、允许 10℃ 温升时，**1mm 宽的走线大约可承载 1~2A**。实际设计建议保留 50% 以上余量，宁可设计得偏宽。

RM 的电池回路电流可达数十安（甚至过百），此类场合不能仅依靠加粗导线，通常采用**整块铜皮 + 多打过孔 + 开窗加锡**的方案。
:::

:::warning 需先确认工厂的工艺能力
嘉立创常规工艺的最小线宽/线距一般在 **5mil（0.127mm）** 左右，免费打样的限制会更多。绘制前应先查阅下单页面的工艺说明——超出工厂工艺能力的尺寸无法正常生产。
:::

#### 过孔

层与层之间可通过过孔连接

![过孔结构](/note1/7e90660a4aa34707856c5fd16a060dd5.jpg)

> 过孔结构：铜壁、焊盘、隔离盘（反焊盘）、过孔残桩

**过孔的作用**：当某一层布线过于拥挤时，可经由另一层绕过障碍。

过孔还有以下要点：

- **分类**：通孔（从顶层打到底层，最常用）、盲孔（从外层打到内层）、埋孔（内层之间）。嘉立创免费打样一般**只支持通孔**
- **三个尺寸参数**：钻孔孔径、焊盘直径、反焊盘（隔离盘）直径
- **残桩（Stub）**：过孔上没有用到的那一段铜。低频下影响可以忽略，高速信号下其效果相当于一根小天线，会影响信号质量，因此高速板会采用盲埋孔或背钻工艺

:::warning 过孔的设计代价

- 每个过孔都要占用焊盘空间，密集布线区域容易造成阻塞
- 过孔存在寄生电感，电源过孔应**多打几个并联**以降低阻抗
- 过孔需要额外的加工费用，孔径越小、板厚越大，工艺难度与成本越高
  :::

:::tip 过孔的载流能力
保守估计，一个 **0.3mm 孔径的过孔可按 1A 载流**计算。需要承载 10A 时，应设置十个以上过孔，并分散布置。
:::

## 学会读数据手册

立创商城往往可以找到一个元器件的数据手册（datasheet），数据手册是了解一款元件的重要渠道。

![立创商城的数据手册入口](/note1/image-20260917201002190.png)

> 检索到型号后点击"数据手册"，即可获取原厂的 PDF 文档

### 数据手册的权威性

数据手册是原厂给出的的技术文档：参数范围、极限值、典型应用电路均以它为准。网络上的电路与电商页面描述可以作为初步参考，但**最终必须以数据手册确认**。器件是否会损坏、参数是否满足要求，只能由数据手册确定。

### 数据手册里应该看什么

| 章节                             | 内容                          | 为什么要看                                 |
| -------------------------------- | ----------------------------- | ------------------------------------------ |
| Features / 概述                  | 主要特性、封装、工作电压范围  | 30 秒快速判断这颗料适不适合                |
| Absolute Maximum Ratings         | 极限参数                      | 超过就永久损坏，绝对不能碰                 |
| Recommended Operating Conditions | 推荐工作条件                  | 设计应该落在这个范围内，而不是"极限范围内" |
| Electrical Characteristics       | 电气特性表（Min / Typ / Max） | 计算电路参数的依据                         |
| Typical Application              | 典型应用电路                  | 官方提供的参考电路，是最安全的起点         |
| Pin Configuration                | 引脚定义                      | 绘制原理图符号时依照此表                   |
| Package Outline                  | 封装尺寸、引脚间距、推荐焊盘  | 核对封装绘制是否正确                       |

:::danger 极限参数不可逾越
**Absolute Maximum Ratings 是"超过即损坏"的界限，而非"可以正常工作"的范围。**

一颗标称 6V 的芯片，绝对最大电压可能标注 7V——但这仅表示"施加 7V 时器件尚未损坏"，绝不代表可以在 7V 下使其工作。真正应当参考的是 Recommended Operating Conditions。
:::

:::tip 阅读顺序

1. 先阅读第一页的 Features，快速判断该器件是否适用
2. 再阅读 Typical Application，官方电路是最安全的起点
3. 然后查阅 Electrical Characteristics，确认需要使用的若干参数
4. 最后核对封装与引脚定义，确认封装绘制无误
   :::

:::info 典型值 ≠ 保证值
电气特性表通常分为 Min / Typ / Max 三列。Typ 仅为典型条件下的数值，不能保证每一颗器件都符合。设计时应做最坏情况分析：该看 Min 的看 Min，该看 Max 的看 Max。
:::

:::warning 注意型号后缀与版本
同一系列芯片往往存在多个型号与后缀，参数可能完全不同。下载手册时，应确认封面上的型号与手头的器件**完全一致**。
:::

## 基本元件

本节介绍硬件组最常使用的几类元器件。选型的基本思路是：**先确认参数是否满足，再确认封装是否正确，最后比较价格与库存**。

### 封装

![常见封装类型](/note1/image-20260917200532807.png)

封装的作用：

- **标准化和兼容性**：不同厂家的同一型号，封装一致即可直接互换
- **保护内部结构**：将脆弱的芯片、电阻体包覆，防潮、防机械损伤
- **提供引脚**：用于连接外部电路的金属端子

封装有不同的大小和引脚分配方式：

| 封装 | 全称               | 特点                                        |
| ---- | ------------------ | ------------------------------------------- |
| DIP  | 双列直插封装       | 传统直插封装，引脚间距 2.54mm，便于手工焊接 |
| SIP  | 单列直插封装       | 仅有一排引脚                                |
| TSOP | 薄型小外形封装     | 引脚位于两侧，封装薄，常见于存储芯片        |
| QFP  | 四边扁平封装       | 四边均有引脚，引脚间距小，需使用热风枪      |
| PLCC | 塑料有引线芯片载体 | 四边 J 形引脚                               |
| LCC  | 无管脚芯片载体     | 四边无引线，通过焊盘焊接                    |

按安装方式，又可以分为**直插**和**贴片**两类：

|          | 直插                             | 贴片                                   |
| -------- | -------------------------------- | -------------------------------------- |
| 焊接方式 | 引脚穿过板子，手焊 / 波峰焊      | 贴在板面，回流焊 / 热风枪              |
| 体积     | 大                               | 小                                     |
| 适用场景 | 大功率、手工练习、需承受机械应力 | 绝大多数场合，尤其是高密度、小体积设计 |

:::tip 贴片封装的"英寸命名法"
0603、0805、1206 这些数字是**英制英寸**，不是毫米：

- 0603 = 0.06in × 0.03in ≈ **1.6mm × 0.8mm**
- 0805 = 0.08in × 0.05in ≈ 2.0mm × 1.25mm
- 1206 = 0.12in × 0.06in ≈ 3.2mm × 1.6mm

公制对应的叫法分别是 1608、2012、3216。在立创商城选购时，页面标注的封装为英制代码，注意不要与自行测量的毫米尺寸混淆。
:::

:::warning 封装错误将导致电路板报废
原理图上的"元件"与 PCB 上的"封装"是绑定关系。封装选择错误（例如 0603 的器件配用了 0805 的焊盘），板子加工回来后只能飞线补救，甚至直接报废。

转换为 PCB 之前，**必须逐个核对封装**。
:::

:::tip 手工焊接友好性

- 电阻电容优先选择 **0603 及以上**的贴片封装，0402 封装用镊子操作已相当困难
- 芯片优先选择引脚间距 ≥ 0.5mm 的型号，便于拖焊
- 常用封装在嘉立创 EDA 库中均已提供，**直接调用即可，无需自行绘制**
  :::

### 电阻

分类：

- 按电阻体材料工艺
  - 厚膜电阻（最常见，精度 1%、5%）
  - 薄膜电阻（金属膜、碳膜，精度更高、温漂更小）
- 按封装
  - 直插（色环电阻）
  - 贴片（0603、1206 等，尺寸以英制英寸命名）

常用：

- 贴片式 厚膜电阻（0603 1206 2512 封装）

![贴片电阻的结构](/note1/image-20260917201614964.png)

> 厚膜贴片电阻的剖面：陶瓷基板、电阻体、内/外保护层与端头镀层

![立创商城上的电阻参数](/note1/image-20260917201002190.png)

[FRC0603F1001TS -PDF 数据手册-参考资料-立创商城](https://item.szlcsc.com/datasheet/FRC0603F1001TS/3180515.html)

:::info 型号命名解读
以图中这颗 `FRC0603F1001TS` 为例：

- `FRC` —— 富捷（FOJAN）的厚膜电阻系列
- `0603` —— 封装尺寸
- `F` —— 精度 **±1%**（±5% 的代码为 `J`）
- `1001` —— 阻值代码，即 1kΩ
- `T` —— 包装方式（编带）

商品页面已列出全部参数：厚膜电阻、1kΩ、±1%、100mW、ROHS，**无需自行推断**。
:::

**贴片电阻丝印的读法**

- 三位数字：前两位是有效数字，第三位是 10 的幂。`103` = 10×10³ = **10kΩ**，`472` = 47×10² = **4.7kΩ**
- 四位数字（±1% 精度常用）：`1001` = 100×10¹ = **1kΩ**，`4702` = 47×10² = **47kΩ**
- `0` 或 `000` = **0Ω**（并非没有电阻，而是阻值接近 0）
- 中间带 `R` 的，`R` 即小数点：`4R7` = **4.7Ω**，`R10` = **0.1Ω**

#### 重要电学参数

- 寄生参数：
  - 寄生电感
  - 寄生电容
  - 贴片电阻的寄生参数很小，低频下基本可以忽略，只有在高频、高精度场合才需要考虑
- 电阻值及容差
  - 常见容差 ±1% ±5%
  - E24（±5% 常用）/ E96（±1% 常用）阻值系列，选型时重要参考
  - 即电阻阻值并非任意取值，只能在标准系列中选择最接近的规格
- 额定功率与功率衰减曲线
  - 0603 约 100mW，0805 约 125mW，1206 约 250mW，2512 约 1W
  - 环境温度越高，可承受的功率越低，这条曲线即**功率衰减曲线**
- 温度系数（TCR）：单位为 ppm/℃，表示温度每变化 1℃ 时阻值的变化量。精密电路应选用低温漂型号

:::warning 功率需留余量
电阻的实际功耗不应超过额定功率的 **50%~70%**。0603 标称 100mW，实际功耗最好控制在 50mW 以内——超出后温升明显，阻值也会随之漂移。
:::

:::tip 采样电阻的选型要求
大电流采样（例如电机电流检测）所用的采样电阻，应选用**低阻值（mΩ 级）+ 低温漂 + 合金材质**的专用采样电阻。若以普通厚膜电阻替代，采样值会随温度显著漂移。
:::

#### 用途

- **分压**：两个电阻串联，将电压按比例分出。例如将 24V 分压后送入仅能测量 3.3V 的 ADC
- **限流**：为 LED、三极管基极串联电阻，防止电流过大损坏器件
- **采样**：串接于回路中，测量其两端电压即可换算出电流（U = I × R）
- **阻抗匹配**：在高速信号线末端接入匹配电阻，减少信号反射
- **上下拉电路**：为信号线提供确定的电平

:::info 上拉/下拉电阻
数字芯片的输入引脚**不能悬空**，否则电平不确定、易受干扰。上拉即将引脚通过电阻接至电源（默认高电平），下拉即接至地（默认低电平）。I2C 的 SDA/SCL 必须各接一个上拉电阻，否则总线无法正常工作。
:::

:::tip 0Ω 电阻的用途
0Ω 电阻虽然看似无实际阻值，但用途广泛：

- 作为**跳线**使用，跨接无法布通的走线
- 实现**单点接地**，将模拟地与数字地在一点连接
- **预留调试位**，便于后期断开线路测量电流或增补器件
  :::

### 电容

分类：

- 按材料工艺
  - 陶瓷电容（MLCC，无极性）
  - 固态（铝电解）电容（有极性）
  - 除此之外还有钽电容、铝电解电容、薄膜电容等
- 按封装
  - 直插
  - 贴片

常用：

- 贴片式 MLCC 多层陶瓷电容（0603、0402、1206 封装），容值小、体积小
- 直插式 固态电容，有极性、容量大、误差大

![MLCC 的封装与尺寸](/note1/image-20260917202917184.png)

> MLCC 的常用尺寸从 0402 到 2220，容值范围从几皮法到几十微法

[CL10B104KC8NNNC -PDF 数据手册-参考资料-立创商城](https://item.szlcsc.com/datasheet/CL10B104KC8NNNC/16407.html)

:::tip 电容丝印的读法
贴片电容（MLCC）一般**没有丝印**，只能查阅包装标签或数据手册。直插的瓷片电容、电解电容上会有标注，读数规则为：

- 三位数字，单位为 **pF**（皮法）：`104` = 10×10⁴ pF = **100nF = 0.1µF**，`103` = **10nF**，`224` = **220nF**，`105` = **1µF**
- 电解电容一般直接将容值与耐压印在外壳上，例如 `100µF 25V`

换算关系：`1µF = 1000nF = 1,000,000pF`
:::

#### 重要电学参数

- **标称容值与误差**：常见 ±5%、±10%、±20%
- **额定电压**：超过将被击穿
  - MLCC 常见 6.3V、16V、25V、50V
  - 电解电容常见 10V、16V、25V、35V、50V
- **ESR/ESL（等效串联电阻/电感）**：ESR 决定纹波与发热，开关电源的输出电容必须选用**低 ESR** 型号
- **温度特性（介质类型）**：

| 介质类型 | 特点                                     | 用途                 |
| -------- | ---------------------------------------- | -------------------- |
| C0G/NP0  | 最稳定，容值几乎不随温度、电压变化       | 振荡、滤波、精密场合 |
| X7R      | 比较稳定，性价比高                       | 通用滤波、去耦       |
| X5R      | 与 X7R 接近，温度范围略窄                | 通用滤波、去耦       |
| Y5V      | 容量大但温漂非常严重，容值随电压衰减剧烈 | 只用于要求不高的场合 |

:::danger 电解电容有极性，反接将导致损坏
固态电容、电解电容是**有极性**的：

- 直插的：**长脚为正极**，外壳上标有 `-` 的色带一侧为负极
- 贴片的：色带 / 缺口一侧为负极

反接轻则导致鼓包漏液，重则直接爆裂。建议在布局时统一所有极性电容的方向，便于检查。
:::

:::warning 耐压需留余量
电容的工作电压不应达到额定电压。一般来说，**实际工作电压不超过额定电压的 50%~80%**：

- 24V 电路上，陶瓷电容至少选择 **50V** 耐压
- 12V 电路上，至少选择 **25V**

此外还需注意 **MLCC 的直流偏压效应**：标称 10µF 的 MLCC，施加额定电压后实际容值可能只剩一半甚至更少。在电源设计中需特别注意这一点。
:::

#### 用途

**储能**

![超级电容组](/note1/image-20260917203415853.png)

> 超级电容组：RM 上用于向底盘提供瞬时大电流

电容的基本功能是储存电荷。超级电容是容量特别大的电容（法拉级），用于在短时间内释放巨大的功率。需注意超级电容单体耐压只有 2.7~3.0V，**必须串联使用，且需配置均压电路**，否则会出现电压不均，最先达到耐压上限的个体将首先损坏。

**滤波**

![Buck 电路中的滤波电容](/note1/image-20260917203441485.png)

> 一颗 SY8205 Buck 电路：输入端 C26/C27，输出端 C31~C36，均为滤波电容

电源中的电容用于抑制电压波动：负载突变时由电容先提供瞬时电流，避免电源响应不及导致电压跌落。

除此之外，电容还常用于：

- **去耦 / 旁路**：在每颗芯片的电源引脚旁放置一颗 0.1µF，将高频噪声就近导入地
- **耦合**：隔直通交，用于传递交流信号而隔断直流分量
- **定时**：与电阻共同决定 RC 时间常数，用于延时、振荡等

:::tip 去耦电容应靠近引脚放置
0.1µF 的去耦电容，与芯片电源引脚的距离**越近越好**（几毫米以内）。距离过远时，中间走线的寄生电感会使其失去作用。

大电容与小电容并联使用：大电容抑制低频波动，小电容抑制高频噪声，各司其职。
:::

#### RC 低通滤波

![RC 低通滤波](/note1/image-20260917203750780.png)

在高频信号下，较大容值不易迅速充满电荷，高频信号的传输因此受到阻碍

截止频率：

$$
f_c = \frac{1}{2\pi RC}
$$

- 低于 $f_c$ 的信号基本原样通过，高于 $f_c$ 的信号被衰减
- 举例：R = 10kΩ，C = 100nF，则 $f_c = \dfrac{1}{2\pi \times 10^4 \times 10^{-7}} \approx 159\,\text{Hz}$，即 159Hz 以上的信号将被逐步衰减

:::warning 该电路的带载能力有限
RC 低通滤波的输出阻抗较高。后级直接接 ADC 采样没有问题，但**无法驱动负载**——接入负载后输出电压会显著下降。需要驱动能力时，应在后级增加一级缓冲（例如运放跟随器）。
:::

:::tip 典型应用
ADC 采样引脚前通常会加一级 RC 低通，用于滤除高频噪声，同时使 ADC 内部的采样保持电容充电更稳定。
:::

### 电感

常用：

- 功率电感

![贴片功率电感](/note1/power-inductor.jpeg)

![各种感值的功率电感](/note1/image-20260917204124176.png)

> 丝印上的 `4R7`、`470`、`100`、`6R8`、`3R3`、`2R2`、`1R5` 即为它们的感值

电感的本质是 **V = L·di/dt**：电感两端的电压正比于电流的变化率，即**阻碍电流变化**——电流增大时产生反向电压，电流减小时维持电流。因此电感可以平抑电流波动，这是它在电源电路中最核心的作用。

:::info 电感丝印的读法

- 带 `R` 的，`R` 即小数点：`4R7` = **4.7µH**，`6R8` = **6.8µH**，`3R3` = **3.3µH**，`2R2` = **2.2µH**，`1R5` = **1.5µH**，`R47` = **0.47µH**
- 三位纯数字：前两位是有效数字，第三位是 10 的幂。`470` = **47µH**，`100` = **10µH**

不同厂家对三位数字的单位定义（µH 或 nH）可能不同，比如线艺电感的单位为 nH，**应以数据手册为准**，不应仅凭丝印推断。
:::

#### 重要电学参数

- **电感量及精度**
- **电感直流电阻（DCR）**：线圈本身的电阻。DCR 越小越好，因为 DCR 上的损耗为 $I^2R$，会直接转化为热量
- **饱和电流及电感衰减曲线**：电流增大到一定程度后磁芯饱和，电感量急剧下降。饱和电流（Isat）通常指电感量降至标称值 70%~80% 时的电流
- 补充两个常看的参数：
  - **温升电流（Irms）**：电感温度上升 40℃ 时的电流，用于评估发热
  - **自谐振频率（SRF）**：超过该频率后，电感将呈现电容特性

:::danger 电感饱和后等效于导线
电感一旦饱和，其等效阻抗接近于零，相当于一根导线。在 Buck 电路中，这意味着电流瞬间失控，开关管与电感本身都可能损坏。

因此选型时 **饱和电流必须大于电路中的峰值电流**，并留出余量（一般 1.3 倍以上）。
:::

#### 用途

- **滤波**
  - 与电容配合，抑制开关电源输出的纹波
- **延迟**
  - 电感阻碍电流变化，因此电流不会突变，天然具有延迟效果

一般在 buck 、boost 电路中使用

:::tip Buck 电路中的电感选型

- **电感量**：决定纹波电流的大小，一般使纹波电流处于输出电流的 20%~40%
- **饱和电流**：应大于峰值电流（= 输出电流 + 一半纹波电流）
- **DCR**：越小效率越高，但通常体积与成本也越高
  :::

### 二极管

分类：

- 按特性与用途
  - 通用二极管
  - 开关二极管：用于信号级的开关与钳位
  - 肖特基二极管：低压降、高速度
  - 稳压二极管：工作于反向击穿区，用于稳压
  - 瞬态抑制二极管（TVS）：用于浪涌保护
  - 发光二极管（LED）：通电发光
- 按封装
  - 直插（DO-41）
  - 贴片（SOD-123、SMA、SMB、SMC）

常用：

- 肖特基二极管（SS34、SS54）
- 开关二极管（1N4148、BAV99）

二极管的基本特性是**单向导电**：电流只能从阳极（+）流向阴极（−），反向截止。

各类二极管的特性对比：

| 类型         | 代表型号         | 正向压降 | 反向恢复时间 | 特点与典型用途                     |
| ------------ | ---------------- | -------- | ------------ | ---------------------------------- |
| 整流二极管   | 1N4007 / M7      | 0.7~1.0V | µs 级        | 成本低，用于工频整流               |
| 开关二极管   | 1N4148           | 约 0.7V  | 4ns          | 速度快、电流小，用于信号级开关     |
| 肖特基二极管 | SS34、1N5819     | 0.3~0.5V | 极短         | 压降低、速度快，用于低压大电流续流 |
| 稳压二极管   | BZT 系列         | —        | —            | 工作于反向击穿区，用于稳压与限幅   |
| TVS          | SMAJ 系列        | —        | 极短         | 吸收浪涌，将瞬时高压钳位           |
| 发光二极管   | 0603 LED、WS2812 | 1.8~3.4V | —            | 通电发光，用于状态指示             |

#### 重要电学参数

- **正向压降（$V_F$）**：导通时的压降，直接决定导通损耗
- **反向耐压（$V_{R}$）**：可承受的最大反向电压，超过将被击穿
- **正向平均电流（$I_{F(AV)}$）**：长期工作的电流上限
- **反向恢复时间（$t_{rr}$）**：由导通切换到截止所需的时间，开关频率越高越重要
- **反向漏电流（$I_R$）**：截止时仍有微小电流流过，肖特基的漏电流较大且随温度显著增大

#### 用途

- **续流**：开关管关断时，为电感电流提供通路（例如 Buck 电路中的续流二极管）
- **防反接**：串接于电源入口，防止电源接反损坏后级电路
- **整流**：将交流电转换为直流电
- **钳位与保护**：配合 TVS、稳压二极管，抑制浪涌与过压

:::tip 二极管的方向性
二极管是**单向导通**的：电流从阳极（+）流向阴极（−），原理图上即三角形指向竖线一侧。方向画反将导致电路板报废。

肖特基二极管导通压降只有 0.3V 左右（普通硅管 0.7V），因此在低压大电流场合（例如 Buck 的续流二极管）几乎为必选方案。
:::

### MOSFET

分类：

- N 沟道 MOSFET（NMOS）
- P 沟道 MOSFET（PMOS）

三个引脚的定义：

| 引脚 | 名称         | 作用           |
| ---- | ------------ | -------------- |
| G    | Gate，栅极   | 控制端         |
| D    | Drain，漏极  | 电流进出的通道 |
| S    | Source，源极 | 电流进出的通道 |

导通条件：

- **NMOS**：栅源电压 $V_{GS}$ 大于阈值电压 $V_{GS(th)}$ 时导通，电流从 D 流向 S
- **PMOS**：栅极电位低于源极（$V_{GS}$ 为负）时导通，电流从 S 流向 D
- 完全导通后，D 与 S 之间等效为一个很小的电阻 $R_{DS(on)}$

关键参数：

| 参数         | 含义         | 怎么看                                         |
| ------------ | ------------ | ---------------------------------------------- |
| $V_{DS}$     | 漏源耐压     | 必须大于电路电压，并留足余量                   |
| $I_D$        | 最大漏极电流 | 结合实际电流和散热条件                         |
| $R_{DS(on)}$ | 导通电阻     | 越小导通损耗越小，注意它随 $V_{GS}$ 和温度变化 |
| $V_{GS(th)}$ | 开启阈值电压 | 该电压为**开始**导通的阈值，而非完全导通电压   |
| $Q_g$        | 栅极总电荷   | 决定开关速度，$Q_g$ 越大驱动越吃力             |

:::danger 栅极不得悬空
MOSFET 的栅极是高阻抗的，悬空时极易受干扰而误导通。因此栅极**必须有确定的状态**：串接一个电阻或 TVS 接至源极
:::

:::warning 3.3V 电平可能无法驱动
普通功率 MOSFET 的 $R_{DS(on)}$ 是在 $V_{GS} = 10V$ 条件下测得的。以 MCU 的 3.3V IO 直接驱动，很可能仅处于"半开"状态，$R_{DS(on)}$ 显著增大，器件将严重发热。

解决办法：选用**逻辑电平（Logic Level）MOSFET**（会标注 $V_{GS} = 4.5V$ 甚至 2.5V 下的 $R_{DS(on)}$），或增加一级栅极驱动电路。
:::

:::tip 选型主要关注两类损耗

- **导通损耗**：$I^2 \times R_{DS(on)}$，因此应选择 $R_{DS(on)}$ 较小的型号
- **开关损耗**：与 $Q_g$ 和开关频率有关，频率越高越明显，因此应选择 $Q_g$ 较小的型号

低压大电流场合（例如 RM 上的电源切换、电机驱动）主要关注 $R_{DS(on)}$；高频开关场合则需重点考虑 $Q_g$。两者通常相互制约，应按实际需求权衡。
:::

#### 用途

- **开关**：以小电压控制大电流回路的通断。RM 上常用于替代继电器、实现过流保护与电源切换
- **负载**：作为功率级的核心器件，驱动电机、电磁线圈等大功率负载

:::info 为何不能由 MCU （推挽/开漏）直接驱动
MCU 的 IO 引脚一般只能输出几十 mA，而电机、电磁铁动辄数安。因此 MCU 仅负责发出控制信号，实际承担功率输出的是 MOSFET。
:::

### 其他常见元器件

- **保险丝**
  - 贴片自恢复保险丝：过流后电阻变大限流，故障排除后自动恢复
  - Littlefuse 保险丝：一次性熔断，熔断后需更换
- **三极管**
  - NPN / PNP 两种
  - 用于小信号放大与开关，成本低于 MOSFET，驱动电路更简单
- **电源接口**
  - 艾迈斯 XT30 系列：RM 上最常用的电源接口，插拔方便，可承受较大电流
- **晶振**：为 MCU 提供时钟，是最小系统的组成部分
- **连接器 / 排针 / 排母 / 接线端子**：板与板、板与线之间的接口
- **传感器**：霍尔传感器、编码器等

:::warning 保险丝应置于最前端
保险丝的作用是通过自身熔断保护后续电路，因此应置于**电源入口、其他所有器件之前**。选择额定电流时：应大于正常工作电流，小于线路与器件的承受能力。
:::

- 从立创商城搜索器件，直接放置到原理图（封装会自动带入）
- 放置器件、旋转、连线；使用**网络标签（Net Label）**代替长距离走线
- 使用交叉选择 / 设计管理器核对网络连接
- 执行编译检查（ERC），处理报错与警告
- 从原理图转换 / 更新到 PCB

:::tip 几个实用要点

- **电源符号（VCC/GND）本质上是网络标签**，同名即相互连接，无需实际拉一根线过去
- 元件位号（R1、C1、U1）必须唯一，重复时 EDA 会报错
- 绘制完成后**不要急于转换为 PCB**，应先执行 ERC 并清除全部错误
  :::

:::warning 演示仅进行一次
初次绘制遇到困难属于正常情况，多加练习即可熟练——**PCB 设计是一项熟能生巧的工作**。
:::
