# 第 1 周 · 环境、器件与电学入门

**9月15日 - 9月21日 · 对应视频第一、二讲**

目标是把"能看懂、能安装、能跑起来"这三件事先做完。这一周不做复杂电路，只建立能继续往下学的底座。

## 本周任务

- 熟悉电脑使用，完成[嘉立创 EDA](/environment/eda) 等必要软件安装（[Multisim](/environment/simulation) 可选）
- 回到高中电学：电阻、电容、电感、三极管，先知道它们在现实里是什么
- 理解 PCB 的作用、结构和生产工艺，不只停留在"能画板"
- 初步学习 C 语言，配置开发环境，独立跑通第一个 `hello world`

:::tip 优先级最高：环境先行
软件装不上会卡住后面所有周。遇到装不上先在群里问，不要自己耗一整天。
:::

## 任务顺序

1. 先装软件，再检查工程文件能否创建和保存
2. 再做器件认知，==最好把实物和图纸对应起来==：拿着买来的电阻去对照原理图符号
3. 随后完成 C 语言最小程序和编译运行
4. 最后下单采购，物料清单见下

## 物料准备

**需要采购：**

| 物品                 | 说明                               |
| -------------------- | ---------------------------------- |
| 面包板               | 免焊接搭电路用                     |
| 阻容器件包           | 插件件与 0603 贴片件都要           |
| LED 包               | 各色直插 LED                       |
| 三极管               | S8050（NPN）、S8550（PNP）         |
| 杜邦线               | 公对公、公对母都备一些             |
| 常用 IC 收纳盒       | 后续几周会陆续买芯片，早点有地方放 |
| STM32F103C8T6 开发板 | 功能由预算决定，第四周才正式用     |

**需要准备：** 个人电脑、嘉立创 EDA 账号、C 语言开发环境、器件收纳盒。
