# 第 4 周 · STM32 系统板与焊接

**10 月 12 日 - 10 月 18 日 · 对应视频第四讲**

这一周进入"从原理到实物"的关键阶段：既要开始按需求配置 STM32，也要把前两周画的板子真正焊出来、跑起来。

:::info 本周的主线
把一块 STM32 板子"能跑起来"所需的五件事认全——**供电、时钟、复位、启动配置、下载调试**——然后用 CubeMX 按需求把外设配出来，最后回到实物把板子焊好、上电验证。讲义看[第 4 周 · 培训讲义](/training/note4)。
:::

## 重点任务

- 搭好 STM32 的软件环境：STM32CubeMX 加工具链，选中 LQFP48 的 STM32F103C8T6 建一个空工程（[环境配置 · 嵌入式工具链](/environment/embedded)）
- 走一遍 CubeMX 的完整流程：选芯片 → 配时钟树 → 配引脚与外设 → 生成代码 → 编译下载
- 把时钟树配到 72 MHz（HSE 8 MHz 经 PLL ×9），并说清 APB1 分频之后为什么定时器时钟仍然是 72 MHz
- 用 GPIO 点亮一颗 LED，再做一个流水灯
- 用通用定时器做一次 1 ms 定时中断，在中断里翻转 LED
- 用外部中断 EXTI 做一次按键触发，并把抖动处理掉
- 把常用外设的引脚模式配对：UART 的 TX 用复用推挽、I2C 的 SDA 用复用开漏、未使用的引脚给出确定电平
- 能对着数据手册说出最小系统五件事各自配错的后果
- 把第二、三周打样的板子焊出来并上电验证，记录每一路的实测电压
- C 语言推进到指针，理解数组、字符串、结构体与指针的关系

:::warning 下载成功不等于跑起来了
BOOT0 悬空、晶振没起振、复位脚被一直拉低，这几种情况都会让程序==下载成功却不运行==。出问题先按"供电 → 时钟 → 复位 → 启动配置"的顺序量一遍，不要先怀疑代码。
:::

## 难点任务

1. **供电引脚不是每款芯片都一样。** F103C8T6 没有 VCAP 引脚；F4 系列有 VCAP_1 / VCAP_2，各要接 2.2 µF；VREF+ 只在 100 脚以上的封装才引出来。换型号就重新看一遍数据手册的引脚定义表。
2. **去耦电容要"先过电容再进引脚"。** 每个 VDD 配一颗 100 nF，紧贴引脚、回流路径尽量短，再并联一颗 4.7~10 µF 的储能电容。漏掉或者走线绕远，表现为随机复位和 ADC 采样跳动。
3. **模拟电源要单独引出。** VDDA 经磁珠与数字 3.3 V 分离，否则 ADC 的采样值会跟着数字电流一起跳。
4. **晶振匹配电容按公式算，不要抄别人的值。** `C = 2 × (C_L − C_stray)`，C_L 查晶振手册、杂散电容一般按 3~5 pF 估。估错不会立刻坏，而是表现为波特率、CAN 位时序、RTC 全部偏一点，也就是"通信偶尔出错"。
5. **BOOT0 必须有确定电平。** 悬空时启动模式不确定，标准做法是 10 kΩ 下拉到地，需要进系统存储器时才用跳帽拉高。
6. **NRST 内部只有弱上拉。** 外部补一颗 100 nF 到地（ST 推荐），并建议并联 10 kΩ 上拉；电容值不对会导致复位不干净。
7. **SWD 引脚不能随便占用。** PA13(SWDIO) / PA14(SWCLK) 或 NRST 一旦被配成普通 IO，调试器就再也连不上，只能拉高 BOOT0 从系统存储器启动，或者在复位瞬间抢连。==务必在 CubeMX 里把这两个脚留成调试口。==
8. **复用功能的引脚必须配成"复用"模式。** 只在 CubeMX 里点亮了外设、没改引脚模式，引脚上不会有任何波形。
9. **代码不要写在 USER CODE 区间之外。** 重新生成工程时会被覆盖，业务逻辑写在 `USER CODE BEGIN / END` 之间。
10. **EXTI 的中断线编号由引脚号决定。** PA0 与 PB0 都占用 EXTI0，不能同时作为中断源。
11. **定时器时钟可能比 PCLK 高一倍。** APB1 预分频不为 1 时，挂在它上面的定时器时钟是 PCLK1 的 2 倍（本例 36 MHz → 72 MHz），按 PCLK 直接算周期会差一倍。另外 ARR 是 16 位，长周期要先取大的 PSC。
12. **中断服务函数要短。** 中断里不做耗时操作，控制周期一般取 1 ms 或 500 µs；高级定时器的互补输出还要设死区，死区时间要大于开关管的关断时间，又不能大到影响占空比精度。

## 焊接与安全规范

:::danger 先看完这段再动烙铁

- 烙铁头温度通常在 300~380 ℃，==碰到皮肤是立刻烫伤==，放下时必须回架
- 助焊剂和焊锡加热会产生烟，**要开窗或开排烟**，不要低头凑在烟上
- 焊完不要用手直接摸刚焊过的焊点和元件
- 第一次上电前先用万用表量电源对地有没有短路
- ==不要一个人在实验室做第一次通电测试==

:::

手焊顺序上的经验：

1. 先焊最矮、最难够到的元件（贴片电阻电容），再焊高的（电解电容、接插件）
2. 芯片先焊一个对角脚固定，确认位置和方向正确后再焊其余引脚
3. 电源部分焊完先单独上电测各路电压，==确认电压对了再焊主控==
4. 焊完用助焊剂清洗剂洗掉残留，否则会腐蚀、也会影响后续测量

## 课后自测

### 最小系统与供电

1. 一块能跑起来的 STM32 板子，最少需要哪五部分？
2. F103C8T6 为什么至少要三颗 100 nF 去耦电容？还要并联多大的一颗，为什么？
3. 板上总电流约 100 mA，用 AMS1117-3.3（压差约 1.7 V）时芯片上损耗多少功率？这个数决定了封装怎么选？
4. VDDA 为什么要经磁珠单独引出，不做分离会看到什么现象？

### 时钟与复位

1. HSI 与 HSE 的区别是什么？为什么正常工作要切到 HSE？
2. 晶振手册给出 C_L = 20 pF、杂散电容按 4 pF 估，匹配电容应取多少？
3. BOOT0 悬空会导致什么现象？标准做法是什么？
4. NRST 外部需要接什么？"上电复位"的实质是什么？

### GPIO 与中断

1. 复用推挽和普通推挽输出有什么区别？为什么 UART 的 TX 必须用复用模式？
2. 为什么 EXTI 里 PA0 和 PB0 不能同时作为中断源？
3. 未使用的引脚为什么要给出确定电平？一般怎么处理？
4. 中断服务函数里为什么不能做耗时操作？控制周期一般取多少？

### 定时器

1. 定时中断的频率公式是什么？定时器时钟 72 MHz、PSC = 71、ARR = 999 时，中断周期是多少？
2. APB1 的 PCLK1 是 36 MHz，为什么挂在它上面的 TIM2 时钟是 72 MHz？
3. F103C8T6 有没有基本定时器？没有会带来什么影响？
4. 互补输出为什么要加死区？死区取值受什么约束？

### CubeMX 与焊接验证

1. CubeMX 生成的是哪一部分代码？业务逻辑写在哪里才不会在重新生成时丢失？
2. 时钟树超限或者 HSE 没起振会有什么现象？排查顺序是什么？
3. 为什么去耦电容要走"先过电容再进引脚"？
4. 上电前和首次上电分别要做什么？（限流、检查项）
