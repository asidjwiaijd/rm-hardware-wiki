# 第 4 周 · STM32、焊接与验证

**10 月 6 日 - 10 月 12 日 · 对应视频第三、第四讲**

这一周进入"从原理到实物"的关键阶段：前两周画的板子要真正焊出来、跑起来。

## 本周任务

- 初步了解 STM32，搭建基于 ==HAL 库== 的开发环境
- 使用 STM32 点亮一颗 LED，进度快者可以尝试流水灯
- 了解 UART、IIC、SPI、CAN 等常见有线通信协议
- 学习焊接基础和安全规范
- 把第二、三周打样的 PCB 焊接并验证
- C 语言推进到指针，深入理解数组、字符串、结构体与指针的关系

:::warning 不要只看视频
焊接、接线、下载程序、串口打印，==这一周至少要跑通一个完整演示链路==。只看完视频而没有实物的话，第五周画最小系统板会非常吃力。
:::

## 任务顺序

1. 先配置 STM32 开发环境（[环境配置 · 嵌入式工具链](/environment/embedded)）
2. 再完成 LED 点亮与基础外设尝试
3. 然后看焊接规范，焊接并调试前几周的板子
4. 最后整理实物图片、视频和 C 语言学习记录

## 四种通信协议速览

先建立整体印象，细节在第六周整合时再深入。

| 协议 | 线数                  | 拓扑     | 典型速率        | RM 上的常见用途              |
| ---- | --------------------- | -------- | --------------- | ---------------------------- |
| UART | 2（TX/RX）            | 点对点   | 115200 bps 起   | 调试打印、与上位机通信       |
| IIC  | 2（SCL/SDA）          | 一主多从 | 100k / 400k bps | 读传感器、EEPROM             |
| SPI  | 4（SCK/MOSI/MISO/CS） | 一主多从 | 数 Mbps         | 高速传感器、Flash、屏幕      |
| CAN  | 2（CANH/CANL，差分）  | 多主总线 | 1 Mbps          | ==电机、裁判系统等车上主干== |

## 焊接与安全规范

:::danger 先看完这段再动烙铁

- 烙铁头温度通常在 300~380 ℃，==碰到皮肤是立刻烫伤==，放下时必须回架
- 助焊剂和焊锡加热会产生烟，**要开窗或开排烟**，不要低头凑在烟上
- 焊完不要用手直接摸刚焊过的焊点和元件
- 第一次上电前先用万用表量电源对地有没有短路
- ==不要一个人在实验室做第一次通电测试==

:::

手焊顺序上的经验：

1. 先焊最矮、最难够到的元件（贴片电阻电容），再焊高的（电解电容、接插件）
2. 芯片先焊一个对角脚固定，确认位置和方向正确后再焊其余引脚
3. 电源部分焊完先单独上电测各路电压，==确认电压对了再焊主控==
4. 焊完用助焊剂清洗剂洗掉残留，否则会腐蚀、也会影响后续测量

## 物料准备

**需要采购：** STM32F103C8T6 开发板、USB 数据线、杜邦线、焊锡丝、助焊剂、吸锡带、排针、热缩管。

**需要准备：** 电烙铁或焊台、焊接支架、万用表、ST-Link、STM32CubeMX、VS Code、前几周打样板和元件包。
