# 第 5 周 · 最小系统板与外设入门

**10 月 13 日 - 10 月 19 日 · 对应视频第六讲**

从"会用开发板"进到"会做开发板"。最小系统板是很好的能力检验点。

## 本周任务

- 了解 STM32 最小系统板的组成
- 在嘉立创 EDA 绘制 STM32F103C8T6 最小系统板，并提交打样
- 学习 GPIO、时钟树、定时器等知识，尝试相关实验

:::tip
这周要开始从"库函数演示"转向**板级设计能力**。用别人的开发板点灯和自己画一块能点亮的板子，中间差的就是这一周。
:::

## 任务顺序

1. 先理解最小系统板由哪几部分组成
2. 再画图，==重点检查供电、复位和下载相关电路==
3. 之后补 GPIO 和时钟树知识
4. 最后做实验并输出说明

## 最小系统板包含什么

一块能跑起来的 STM32 板子，最少需要这些：

| 部分     | 内容                                  | 容易出错的地方                       |
| -------- | ------------------------------------- | ------------------------------------ |
| 供电     | 3.3V 稳压，每个 VDD 引脚配去耦电容    | ==去耦电容漏掉或离引脚太远==         |
| 复位     | NRST 上拉 + 复位按钮 + 电容           | 忘记上拉，或电容值不对导致复位不干净 |
| 时钟     | 8MHz 晶振 + 两只匹配电容              | 电容值没按晶振手册选                 |
| 启动配置 | BOOT0 / BOOT1 跳帽或电阻              | BOOT0 悬空导致启动模式不确定         |
| 下载调试 | SWD 接口（SWDIO / SWCLK / GND / 3V3） | ==没引出 GND 或电源，调试器认不到==  |
| 指示     | 电源灯 + 一颗可编程 LED               | 限流电阻算错                         |

:::warning
画完先自查一遍：**每个 VDD 都有去耦电容吗？SWD 四根线都引出来了吗？BOOT0 有确定的电平吗？** 这三项是新手打样回来点不亮的最常见原因。
:::

## 时钟树要理解什么

不用背，但要能回答：

- 系统时钟 SYSCLK 从哪来（HSI 内部 / HSE 外部晶振 / PLL 倍频）
- 外设挂在 APB1 还是 APB2，它们的分频是多少
- 为什么定时器的时钟有时候是 APB 时钟的 2 倍

STM32CubeMX 的 Clock Configuration 页面会把整棵树画出来，改完能立刻看到每个节点的频率，==比看手册直观得多==。

## 物料准备

**需要采购：** STM32F103C8T6 芯片、8MHz 晶振及配套电容、复位按钮、BOOT 跳帽、电容、稳压器、SWD 接口座、排针座、指示灯、电阻。

**需要准备：** 嘉立创 EDA 原理图库与封装库、下载器和编程线、万用表、调试记录模板。
