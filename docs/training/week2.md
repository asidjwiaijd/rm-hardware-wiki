# 第 2 周 · 典型电路、仿真与 PCB

**9 月 22 日 - 9 月 28 日 · 对应视频第二讲等**

这一周要从"看懂器件"走向"把器件拼成能工作的电路"。

## 本周任务

- 用面包板点亮 LED，尝试用电位器控制亮度
- 在上一步基础上加入三极管控制，==重点理解饱和区工作方式==
- 学习运算放大器原理和电路分析方法，仿真验证常见运放电路
- 使用仿真软件完成电赛校内赛第一题两问
- 把上述电路转到嘉立创 EDA 绘制 PCB，并提交打样
- C 语言继续推进到变量、函数、基本运算符

:::warning 重点：先仿真，再上板
这一周最容易出错的地方不是"画不出来"，而是**原理没吃透就直接抄图**。抄来的图在仿真里跑不通，打样回来也一样跑不通，而打样一轮就是一周。
:::

## 任务顺序

1. 先完成 LED 电路和亮度调节
2. 再做三极管控制，==记录开关状态和电流变化==
3. 随后做运放电路仿真，必要时用面包板验证
4. 最后整理 PCB 截图和原理解释报告

## 关于三极管饱和区

这是本周最容易糊弄过去的知识点。判断三极管工作在哪个区，看两个结的偏置状态：

| 工作区     | 发射结 | 集电结 | 典型用途     |
| ---------- | ------ | ------ | ------------ |
| 截止区     | 反偏   | 反偏   | 开关"关"     |
| 放大区     | 正偏   | 反偏   | 线性放大     |
| **饱和区** | 正偏   | 正偏   | **开关"开"** |

做开关用时要确保基极电流足够把管子推进饱和区，否则管子会工作在放大区、白白发热。

## 物料准备

**需要采购：** 运放芯片（如 LM324、LM358）、蓝白电位器、打样所需基础元件。

**需要准备：** 嘉立创 EDA 账号、万用表、仿真软件元件库（若用 Multisim）。
