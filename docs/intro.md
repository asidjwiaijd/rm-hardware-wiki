# 从这里开始

这是 RM 苍穹战队硬件组的培训与知识库。内容面向**刚进组、还没做过硬件**的新队员，也可以当成老队员查资料的入口。

## 硬件组做什么

硬件组负责机器人上跑电的那部分：从电池到各路电源、从主控到各个模块、从原理图到打样回来的板子。

和电控组的分工是这样的：

|          | 硬件组                                 | 电控组                       |
| -------- | -------------------------------------- | ---------------------------- |
| 主要产出 | 原理图、PCB、焊好的实物板              | 跑在板子上的固件             |
| 常用工具 | 嘉立创 EDA、万用表、焊台、示波器       | STM32CubeMX、VS Code、调试器 |
| 芯片范围 | STM32 之外还有各种电源、驱动、接口芯片 | 主要围绕 STM32               |

:::info
硬件组也要写代码，只是不止写 STM32。==所以我们的开发环境用 VS Code 而不是绑死单一芯片的 IDE==，这一点在[开发环境](/environment/devtools)里有解释。
:::

## 怎么用这个站

1. **跟着周计划走** —— [本周该做什么](/schedule)会自动算出今天属于第几周，直接点进去看任务。
2. **先配环境** —— 第一周的大半时间都花在装软件上，[环境配置](/environment/)把下载链接和坑都列好了。
3. **需要买东西时查物料** —— 每周页面末尾有当周清单，[物料总表](/resources/bom)是七周汇总。
4. **找具体知识点用搜索** —— 右上角搜索框支持中文，比翻侧边栏快。

## 关于考核

考核任务**主要起学习引导作用，鼓励实操**，采用自愿提交方式。

:::tip
提交物的形式很宽松：文档、截图、照片、演示视频、原理说明都算。重点是能看出你真的动手做了，而不是把视频看完了。
:::

:::warning
涉及**焊接、锂电池、通电调试**的环节有实际风险。第四周之前请先看完[焊接与用电安全](/training/week4#焊接与安全规范)一节，不要在没人的时候第一次上电。
:::

## 内容准确性

这份文档由队员自己维护，不是官方手册。

- 器件价格、打样规则、软件版本都会变，页面底部标了**最后更新时间**，看到过期内容请直接改
- 涉及具体参数和规则的地方尽量标了来源；没有来源的地方会用 <Note>需要验证</Note> 标出来
- 每页底部有**页面历史**和**贡献者**，能看出这一页是谁写的、什么时候改的
