# 如何交作业？

交作业须提交**可打开的工程源文件**，而非截图或 Gerber，以便批改时能够打开、查看与复核。

## 操作步骤

1. 在左侧**工程树**中找到本次作业对应的工程，其中通常包含「原理图」「PCB」等多个条目。
2. 右键 **「板子」**——需要右键的是板子本身，而非「原理图」，也非「PCB」。
3. 在弹出的右键菜单中选择 **「文档另存为（本地）……」**。
4. 将导出的工程文件提交。
