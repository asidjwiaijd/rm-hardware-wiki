# 电路仿真

## Multisim

[NI 官方下载页](https://www.ni.com/zh-cn/support/downloads/software-products/download.multisim.html)

NI 公司（National Instruments）推出的电路仿真和设计软件。主要用途是搭建虚拟电路原理图，通过软件模拟电路运行状态，验证电路拓扑、观察各节点的电压电流波形。

:::info Multisim 是可选项
Multisim 体积大、安装麻烦，==不是必须的==。能达到同样目的的替代品都可以：

- **LTspice** —— ADI 出品，免费，电源仿真尤其常用
- **TINA-TI** —— TI 出品，免费，配合 TI 的芯片模型很方便
- **嘉立创 EDA 自带仿真** —— 简单电路够用，不用另外装软件
- **Falstad 在线仿真器** —— 浏览器里就能跑，适合快速验证一个想法

第二周的任务是"用仿真软件验证运放电路"，==用哪个工具不重要，能跑出波形并解释清楚就行==。
:::

## 为什么一定要仿真

第二、三周反复强调"先仿真再上板"，原因很实际：

|                  | 改一次的代价             |
| ---------------- | ------------------------ |
| 仿真里发现问题   | 几分钟                   |
| 面包板上发现问题 | 几十分钟                 |
| 打样回来发现问题 | ==一周，外加一张打样券== |

:::warning
仿真跑通不等于板子一定能工作。仿真里没有走线电阻、没有寄生电感、没有焊接不良。==仿真验证的是拓扑和参数，不是工艺==。
:::
