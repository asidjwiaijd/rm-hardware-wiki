# PCB 设计工具

## 嘉立创 EDA 专业版

[下载链接](https://pro.lceda.cn/)

国产 PCB 设计工具，深度整合立创商城元器件库，==无需手动绘制常见封装==。支持团队协作和云端存储，是硬件组主力设计软件。

安装最新稳定版，注册嘉立创账号后使用。**首次启动时建议同步官方标准库**，否则画图时会找不到元件。

:::tip 为什么用它而不是 Altium

- 元件库和立创商城打通，选型时能直接看到有没有货、多少钱
- 免费，不用折腾授权
- 打样流程一键直达，不用导出 Gerber 再上传
- 团队协作和云端工程，换电脑不用拷文件

:::

## 嘉立创下单助手

[下载链接](https://download1.sz-jlc.com/download/jlc-order-assistant.html)

用于将 PCB 工程直接下单打样。

::: info 免费打样券
每月可领取 ==两张== 免费打样券，限制条件：

- 尺寸 10cm × 10cm 以内
- 板厚 1.6mm
- 常规工艺

培训期间的板子基本都在这个范围内，记得每月领。
:::

:::warning
打样有周期，从下单到拿到板子通常要几天。第二、三周的板子==越早提交越好==，否则第四周焊接环节会没有板子可焊。
:::
